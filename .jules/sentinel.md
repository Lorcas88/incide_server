## 2024-05-18 - Fix SQL Injection Vulnerability in BaseModel.findOne
**Vulnerability:** The `findOne` method in `BaseModel` iterated over the `conditions` object keys and directly interpolated them into the SQL query string using template literals (e.g., `this.where(\`\${this.table}.\${key} = ?\`, [values[index]])`). If a malicious user controlled the keys of the `conditions` object, they could inject arbitrary SQL into the query.
**Learning:** The query builder correctly used parameterized bindings (`?`) for values but assumed the object keys (column names) were inherently safe and trusted. This pattern shows a misunderstanding of how template literals can still be vulnerable if the interpolated variables originate from untrusted input, even when using prepared statements for the values.
**Prevention:** Always validate or sanitize dynamic column names against a strict allowlist or regex (e.g., `/^[a-zA-Z0-9_]+$/`) before interpolating them into SQL queries. Never blindly trust the keys of an object used to construct database queries.
