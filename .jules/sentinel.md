## 2024-05-24 - [SQL Injection via Dynamic Object Keys in Model Conditions]
**Vulnerability:** The `findOne` method in `BaseModel` (`src/core/base.model.js`) dynamically constructed `WHERE` clauses by directly interpolating object keys from the `conditions` parameter into the SQL string (`this.where(\`${this.table}.${key} = ?\`, [values[index]])`). If user input (like a token or ID) was passed as an object key instead of a value, it could lead to SQL injection.
**Learning:** Even when using parameterized queries (`?`) for values, dynamically interpolating object keys directly into SQL strings without validation can introduce SQL injection vulnerabilities. The query builder needs strict allow-lists or format validation for column names/keys.
**Prevention:** Always validate dynamically generated column names or object keys used in SQL construction. Implement a strict regex check (e.g., `/^[a-zA-Z0-9_]+$/`) to ensure the key is only composed of valid alphanumeric characters and underscores before using it in a query.
